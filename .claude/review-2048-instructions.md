## 검증 방법
1. 먼저 `/apps/2048/index.html`, `style.css`, `game.js` 코드를 꼼꼼히 읽어 로직 오류, 오타, 접근성 문제를 점검하세요.
2. **실제 브라우저로 동작을 확인하세요.** 로컬 서버를 띄운 뒤 (예: `python -m http.server 8080` 등을 `/apps/2048/` 또는 블로그 루트에서 실행) 내장 브라우저 도구로 `http://localhost:8080/apps/2048/index.html` (또는 해당 경로)을 열어:
   - 보드가 4x4로 정상 렌더링되고 타일 2개로 시작하는지.
   - 방향키(←↑→↓)로 타일이 이동/병합되고 점수가 올라가는지 (키보드 이벤트를 보낼 수 없다면, 화면/구조 확인 + 코드 리뷰로 판단해도 되지만, 가능하면 실제로 key 이벤트를 시뮬레이션해서 확인).
   - "새 게임" 버튼 동작.
   - 다크모드 토글 동작 및 새로고침 후 유지(localStorage).
   - 브라우저 콘솔에 에러가 없는지 (`read_console_messages` 등 활용).
   - 모바일 폭(360px~480px)으로 뷰포트를 줄여서(`resize_window`) 레이아웃이 깨지지 않는지 확인.
3. spec.md의 "7. 완료 기준(DoD)" 체크리스트를 하나씩 확인하세요.
4. 문제를 발견하면 `/apps/2048/` 내부 파일을 직접 수정해 고치세요. 수정 후 다시 브라우저로 재확인하세요.
5. 최종적으로 `C:\Users\chang\Desktop\재가복지센터\블로그\review.md`를 작성하세요. 포함할 내용:
   - 검증 방법(로컬 서버 실행 방식, 브라우저 테스트 내역).
   - DoD 체크리스트 각 항목의 통과 여부.
   - 발견한 문제와 수정 내역(있다면).
   - 남은 이슈나 한계(있다면).
   - 최종 결론: 임베드(Embed) 단계로 넘어가도 되는지 여부.
