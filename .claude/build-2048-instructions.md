## 구현 기준
루트의 `C:\Users\chang\Desktop\재가복지센터\블로그\spec.md`에 작성된 기획을 그대로 구현 기준으로 삼으세요. spec.md를 먼저 전체 읽고 시작하세요. 요약하면:

- 폴더: `/apps/2048/` 안에 `index.html`, `style.css`, `game.js` 3개 파일만 생성.
- 4x4 보드, 방향키(←↑→↓) 입력으로 타일 이동/병합(2048 게임 표준 규칙), 랜덤 타일 생성(90% 확률 2, 10% 확률 4).
- 점수판: SCORE(현재 점수), BEST(최고 점수, `localStorage` 키 `game2048-best`에 저장).
- 게임오버 판정(더 이상 이동 불가), 2048 달성 시 승리 오버레이("계속하기"로 이어서 플레이 가능), "새 게임" 버튼.
- 모바일 터치 스와이프 지원(최소 스와이프 거리 적용), 360px~ 반응형 레이아웃.
- 독립적인 다크모드 토글(`localStorage` 키 `game2048-theme`, 시스템 `prefers-color-scheme` 감지, `<html data-theme="dark|light">` 방식). 블로그의 `css/style.css`, `js/theme.js`는 디자인 톤(색감·라운드 처리) 참고만 하고 import/복사하지 않습니다.
- 순수 HTML/CSS/JS, 프레임워크·빌드 도구·외부 라이브러리 없음.
- spec.md의 "7. 완료 기준(DoD)" 체크리스트를 모두 충족해야 합니다.
